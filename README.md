## ПРОЕКТ: Игра "2048"
**Авторы:** Кушу Ислам и Панеш Алибек, группа ИС-2 (2).

## ЗАПУСК:
- Установить зависимости: pip install -r requirements.txt
- Запустить программу: python main.py

## ОПИСАНИЕ:
Программа представляет собой реализацию игры "2048". Пользователь
нажимает стрелки или WASD и перемещает клетки со значениями. 
Соседние клетки с одинаковыми значениями складываются. 
Цель игры - набрать клетку со значением 2048 или больше.

## ТРЕБОВАНИЯ:
- Python 3.9+
- Библиотеки: customtkinter, tkinter
